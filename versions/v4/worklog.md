## 주의사항

- v3와 v4는 같은 DB지만 기존 테이블/61건의 응답은 그대로 보존.
- 새 4차 응답은 v4_responses에 저장하며 v3에서는 집계되지 않음.
- 테스트 응답 60건의 접수번호는 26~85. 식별 기록은 deploy/test_surveys_20261009_60.json.
- .env와 DB 백업은 비공개 유지. Google Charts 로딩에는 인터넷 연결 필요.
- 기존 가상환경은 복사하지 않았으며 v3 가상환경을 사용해 실행 가능.

## 탭 동작 수정 — 2026-10-09

- 이전 v3 admin.js가 재사용되면 새 탭에 이벤트가 연결되지 않는 현상을 모의 캐시로 재현.
- HTML의 정적 파일 URL에 버전 v=4.0.1 추가, HTML·JS·CSS와 v4 API에 Cache-Control: no-store 적용.
- Google Charts 연결 실패 상황에서도 두 탭과 키보드 이동이 정상 동작하는 회귀 검증 통과.
- 8003 서버 재시작 및 응답 헤더 확인 완료. 브라우저에서 새로고침 후 적용.

## 분석 그래프 표시 개선 — 2026-10-09

- 파이조각에 비율을 항상 표시하고 각 조각을 양쪽 범례와 직선으로 연결.
- 점수 수직 막대그래프 X축: 1 매우 낮음 · 2 낮음 · 3 보통 · 4 높음 · 5 매우 높음.
- 세 파이차트 및 네 점수 그래프의 실제 브라우저 렌더링 검증 완료.

- 파이 범례를 조각 가까이에 굵은 글씨로 배치하고 색상별 직선 연결. 범례 아래 비율 제거, 조각 안 비율 유지. 세 파이차트 및 모바일 범례 경계 검증 통과.
- 파이차트를 3D로 전환하고 연결선을 수평·수직 직각 경로로 변경. 실제 3D 타원 가장자리에 연결점을 배치하며 굵은 범례와 조각 안 비율 유지. 세 차트의 직각 경로와 모바일 배치 검증 완료.
