# 화면 검증

v4 서버를 8003에서 실행한 상태에서 이 폴더의 npm 의존성을 설치하고 검증합니다.

```powershell
npm.cmd install
npm.cmd test
```

기존 Chrome의 별도 헤드리스 프로필을 사용합니다. 관리자 계정은 v4의 .env에서 읽습니다.
실제 61건 조회, 차트 7개, 페이지 이동, 상세 조회, 탭 전환을 확인합니다.
항목 추가·수정·삭제 및 설문 제출은 브라우저의 모의 응답으로 확인하며 DB를 변경하지 않습니다.
실제 저장 경로는 test_questions.py의 DB 통합 테스트에서 트랜잭션 롤백으로 검증합니다.
서버에 응답을 추가했다면 고정된 61건 기대값은 현재 건수에 맞게 수정하세요.

탭 캐시 회귀 검증: `npm.cmd run test:tabs`. 이전 unversioned 스크립트와 Google Charts 연결 실패를 모의 처리하여 두 탭·키보드 전환을 확인합니다.
