# Lecture Online Survey

강의 온라인 설문 프로그램의 버전별 소스와 문서입니다.

- `versions/v1`: 초기 버전
- `versions/v2`: 2차 버전
- `versions/v3`: 3차 버전
- `versions/v4`: 4차 버전과 관련 개발 문서
- `versions/github-release`: 배포용 버전과 PostgreSQL/Cloud Run 문서

각 폴더의 README와 requirements 파일을 참고하세요. 환경설정 예시는 포함되며, 실제 .env, DB 백업, 비공개 이전 데이터, 가상환경 및 로그는 제외했습니다. 문서에 포함된 실제 관리자 비밀번호는 가렸습니다.
